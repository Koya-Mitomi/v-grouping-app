# V-GROUPING App（バレーボールチーム管理アプリ）

バレーボールの大会・練習・イベントで使える、**プレイヤー管理**と**チーム分け（手動/自動）**を行うためのWebアプリです。  
過去イベントのチーム構成を保存して見返すこともできます。

---

## 主な機能

- **プレイヤー管理**
  - プレイヤーの追加 / 編集 / 削除
  - 一覧表示（ページネーション、ソート）

- **イベント管理**
  - イベントの作成 / 編集 / 削除
  - 一覧表示（ページネーション、ソート）

- **チーム分け**
  - 参加プレイヤーの選択
  - **手動でチームを作成**（メンバー追加・削除）
  - **自動でチームを生成**（ランダム生成）
    - 生成し直し（再生成）可能
    - 条件（ポジション/レベル/学年/性別などの偏り考慮）

- **履歴**
  - イベントごとのチーム構成を保存して後から確認

---

## 画面/ルーティング（例）

- ホーム: `/`
- 使い方: `/howToUse`
- プレイヤー一覧: `/players`
- イベント一覧: `/events`
- イベント詳細: `/events/[id]`

## セットアップ

### 1) 依存関係のインストール

```bash
npm install
```

### 2) 環境変数の設定

Supabaseを利用している場合、`.env.local` を作成し、必要な値を設定してください。

例：

```bash
NEXT_PUBLIC_SUPABASE_URL=xxxx
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=xxxx
```

### 3) 開発サーバー起動

```bash
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。
